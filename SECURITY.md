# Security policy

If you find a weakness in these workflows, such as a prompt injection that changes a verdict, a way past the allowlist, or a page that makes the bot call a scam safe, please report it privately rather than in a public issue: use **Security → Report a vulnerability** on this repository.

Please include the input that triggers it and the verdict you got. Reports are answered on a best-effort basis; this is a family project, not a product.

Phishing pages and scam stores themselves are not vulnerabilities in this project. To share one as a test case, open an issue with every link defanged (`hxxps://example[.]com`).
